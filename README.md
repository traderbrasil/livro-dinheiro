# Dinheiro: Querer, poder e gastar (2ª edição): laboratórios e planilhas

Hub do livro: https://www.traderbrasil.com/livro-dinheiro/

## Como usar

Clique em "Abrir no Colab": o notebook roda direto na internet, sem instalar nada. Na primeira vez, o Colab pede para você entrar com uma conta do Google. Os campos marcados com `# MUDE AQUI` aceitam os seus números.

A versão `v2.0` é a que foi congelada na impressão do livro (dados conferidos em outubro de 2026). Os notebooks baixam os dados no dia em que você roda; por isso, os seus números podem ser diferentes dos do livro.

## Fontes de dados

- Banco Central do Brasil, Sistema Gerenciador de Séries Temporais (SGS): https://www3.bcb.gov.br/sgspub
- IBGE, SIDRA: https://sidra.ibge.gov.br
- Tesouro Nacional, Tesouro Transparente (preços e taxas do Tesouro Direto): https://www.tesourotransparente.gov.br
- Yahoo Finance, pela biblioteca `yfinance` (índices em pontos, sem dividendos).

As simulações são projeções com as hipóteses de quem as roda, e não promessas. Investir envolve risco, inclusive o de perder parte ou todo o capital.
